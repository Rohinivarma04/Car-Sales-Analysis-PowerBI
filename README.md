# Car-Sales-Analysis-PowerBI

 ##Project Overview
Interactive Power BI dashboard developed to analyze car sales performance.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Analysis
- YTD and MTD sales
- Average car price
- Cars sold
- Sales trends
- Sales by body style
- Sales by color
- Dealer region analysis
- Company-wise analysis

## Dashboard
The dashboard provides interactive KPIs, charts, and slicers for exploring car sales data.
